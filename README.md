# ArcheAge Chronicles — RU / UA

Установка готового фанатского перевода игры на русский или украинский язык. Для игрока: два батника и файлы перевода. Ключи, редактор, извлечение игровых архивов и установка дополнительных программ не нужны.

## Скачать и установить

1. Откройте [Releases](https://github.com/lUjek-Sh/ArcheAge-Chronicles-RU-UA/releases/latest) и скачайте архив **ArcheAge-Chronicles-RU-UA-версия.zip**.
2. Распакуйте **весь** архив. Можно положить его в папку игры или в любую другую папку: установщик ищет игру в библиотеках Steam.
3. Закройте игру и запустите **Install-or-Update.cmd**.
4. В меню выберите **1 — Русский** или **2 — Українська**. Установщик проверит последний опубликованный GitHub Release и установит выбранный язык.

Если язык ещё не опубликован, установщик сообщит об этом. Наличие пункта в меню не означает, что перевод этого языка уже готов.

## Обновление, смена языка и удаление

- После публикации новой версии снова запустите **Install-or-Update.cmd**. Новый файл скачивается только при отличии SHA256. Фоновых задач и автоматического запуска при старте Windows нет.
- Чтобы сменить RU ↔ UA, запустите тот же батник и выберите другой язык.
- **Remove-Translation.cmd** удалит файлы, установленные этим комплектом, восстановит прежние файлы из резервных копий и выберет английский язык. То же действие есть в меню под номером 3.
- При недоступном GitHub можно установить файлы из скачанного архива. Не удаляйте из архива `manifest.json`, `String-ru.locres` и `String-uk.locres`, если они в нём есть.

При отказе доступа к папке игры запустите батник от имени администратора. Если язык переопределён параметрами запуска Steam (`-culture=…`), удалите или измените этот параметр.

## Что изменяется в игре

Переводы устанавливаются отдельными файлами, без изменения `.pak`:

- русский: `X5/Content/Localization/String/ru/String.locres`, `Culture=ru`;
- украинский: `X5/Content/Localization/String/uk/String.locres`, `Culture=uk`.

Установщик проверяет размер и SHA256 до записи в игру, сохраняет резервные копии в `X5/Localization-RU-UA/`, сохраняет кодировку и остальные настройки `GameUserSettings.ini`. При несовпадении сборки игры и перевода выводится предупреждение: часть изменённых строк может остаться в оригинале.

## Українською

Завантажте повний архів із Releases, розпакуйте його та запустіть **Install-or-Update.cmd**. Виберіть **2 — Українська**. Для оновлення або зміни мови використовуйте цей самий файл. **Remove-Translation.cmd** видаляє переклад і повертає англійську мову. Редактор, ключі та файли оригінальної локалізації гравцеві не потрібні.

Це неофіційний фанатський проєкт. Помилки перекладу можна повідомляти через [Issues](https://github.com/lUjek-Sh/ArcheAge-Chronicles-RU-UA/issues).
